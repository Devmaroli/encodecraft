# encodecraft-job

Shared enqueue types for [EncodeCraft](../..) and [EffectCraft](https://github.com/storytold/effectcraft).

Dependencies: `serde`, `serde_json`, `thiserror`. No FFmpeg, no egui.

```toml
encodecraft-job = { path = "../encodecraft/crates/job" }
```

See `docs/job-format.md` in the EncodeCraft repo.
