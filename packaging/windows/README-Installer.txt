EncodeCraft Setup (Windows 64-bit)
==================================

Double-click  EncodeCraft-Setup-x64.exe

This installer does not need administrator rights. It copies EncodeCraft into:

  %LOCALAPPDATA%\Programs\Craft\EncodeCraft

and adds Start menu and desktop shortcuts. The window icon is Frame E in
Electric Cobalt. FFmpeg and ffprobe are included in that folder.

Settings (queue, presets) stay in your user profile:

  %APPDATA%\EncodeCraft\EncodeCraft\data

Uninstall from Settings → Apps, or Start → EncodeCraft → Uninstall EncodeCraft.
Your encoded files and %APPDATA% settings are left in place.

First launch may show “Windows protected your PC” (the download is not
code-signed). Click More info → Run anyway.

Need a USB / no-install copy instead? Use EncodeCraft-Portable-x64.zip.
